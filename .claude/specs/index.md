* [Design: worldvault Template and worldbuilder-setup Skill](2026-05-28-vault-template-design.md) - Design for the pre-configured worldvault Obsidian vault template and the worldbuilder-setup skill that installs it into new projects.
* [Design: World Entity Note Skills — Location, Faction, Concept Depth](2026-05-28-world-entity-notes-design.md) - Design applying the character blueprint's behavioral-specification reframing to location, faction, and concept notes.
* [Character Blueprint Rework — Design Spec](2026-06-03-blueprint-rework-design.md) - Design for eliminating redundancy in the character blueprint by restructuring Soul, Behavioral Descriptions, and Relationship Behavior into behavioral sections.
* [Retool worldbuilder-skills on scraibe base](2026-07-04-retool-worldbuilder-skills-on-scraibe-base.md) - Strip note-taking/vault management from worldbuilder skills; scraibe owns file management via OKF. This plugin defines worldbuilding types and deliverables only. First live trial of scraibe as a base plugin.
* [Writing-doctrine blind-trial kit](2026-07-11-writing-doctrine-blind-trial-kit.md) - Portable kit a worldbuilding project runs on one pending character: six-arm factorial blind trial (3 doctrine levels x 2 style rule sets) gating the stop-slop integration and the character-doctrine fold-in.
* [Standing writing-assessment methodology: A/B trial suite and production self-review battery](2026-07-26-standing-writing-assessment-methodology-a-b-trial-suite-and-production-self-review-battery.md) - Two-part assessment system: a standing A/B testing suite (trials/METHODOLOGY.md) generalized from the 2026-07 writing-doctrine trial, and an automated self-review battery for the production character-card workflow, connected by a graduation rule: a mechanism ships in production only after the suite validates it.
* [Cross-model convergence metric validation experiment](2026-07-30-cross-model-convergence-metric-validation-experiment.md) - Validation experiment for the cross-model convergence check (METHODOLOGY.md 4.4): parallel generation across four models (Opus 4.6, Opus 5, GPT-5.6 Sol, GPT-5.6 Terra), three detection methods, correction pass, and human review on two characters
* [Character Generation Pipeline v2 — Input Restructuring, Doctrine Additions, and Grader Agent](2026-07-31-character-generation-pipeline-v2-input-restructuring-doctrine-additions-and-grader-agent.md) - deprecated, superseded by [2026-08-15-character-card-architecture-q-a-workflow-block-model-and-export-interface](2026-08-15-character-card-architecture-q-a-workflow-block-model-and-export-interface.md)
* [Additive-Doctrine Discriminator Trial](2026-08-09-additive-doctrine-discriminator-trial.md) - Trial using graduated detection components (input-echo, within-model divergence) as mechanical discriminators to validate or challenge the additive-doctrine adoption. 3 arms (current, additive, stopslop) × 2 characters (Nadja, Kallya) × 3 runs × 2 models (Sonnet, Opus) = 36 generations, no blinding.
* [Export-Standards Review: Keywords Field and Extraction Reliability Map](2026-08-10-export-standards-review-keywords-field-and-extraction-reliability-map.md) - Review of Hoplight and export-format standards (CCv3, ST worldinfo, charx, canonical model) applied to internal note structure. Adds optional keywords field to lorebook-bound note types and defines an extraction reliability map classifying every export-target field by derivation method.
* [Pipeline quality trial — fail-check gate, input restructuring, and decomposition step](2026-08-13-pipeline-quality-trial-fail-check-gate-input-restructuring-and-decomposition-step.md) - Experiment comparing three pipeline improvement approaches for reducing echo and slop in character note generation
* [Writing style trial — STE-100 and semantic anchors](2026-08-14-writing-style-trial-ste-100-and-semantic-anchors.md) - Trial comparing character note generation under different writing style constraints: current baseline, strict STE-100, loose STE-100, and BLUF
* [Card Format Amendments — Body Appearance Preamble and Story Beats Addon](2026-08-15-card-format-amendments-body-appearance-preamble-and-story-beats-addon.md) - Two amendments to card-format.md: (1) a prose preamble in Body for static appearance, exempt from the staging test; (2) a Story Beats addon block for triggerable narrative scenarios with labeled prose entries.
* [Character Card Architecture — Q&A Workflow, Block Model, and Export Interface](2026-08-15-character-card-architecture-q-a-workflow-block-model-and-export-interface.md) - Replaces the generation pipeline with a Q&A-into-card workflow. Defines the card format (Core block with Background/Body/Soul, addon blocks for Relationships, Intimate Dynamics, and Voice/Dialogue) and the conversational extraction workflow. Based on the research audit findings.
* [Source Ingestion Skill — Reference Document Structure and Extraction Principles](2026-08-15-source-ingestion-skill-reference-document-structure-and-extraction-principles.md) - Defines the worldbuilder source ingestion skill: what it produces (source-organized reference documents), the no-inference principle (extraction only, no interpretation), source-type guidance for game assets, existing cards, fiction, and external references.
* [Worldbuilder document review gate](2026-08-15-worldbuilder-document-review-gate.md) - Pre-completion adversarial review step for all worldbuilder documents — standalone review skill with format-doc-embedded acceptance criteria, auto-fix of clear violations, and escalation of ambiguous findings
* [Restructure Discussion Notes — 2026-05](restructure-notes.md) - Working notes from design discussions capturing decisions on platform decoupling, note structure, and pipeline restructuring ahead of formal ADRs.
