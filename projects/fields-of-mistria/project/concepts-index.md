# Fields of Mistria — Concepts Index

Inventory of world systems, ecology, and cultural concepts for entity
document creation. These are the setting's rules and texture — what
makes this world distinct from a generic farming sim.

## Concept document format

Each concept's working document will contain:

- **Name** — what the system/concept is called
- **Description** — what it is, how it works in the world
- **Entities involved** — which locations, NPCs, events it touches
- **Roleplay relevance** — what a player or AI portraying this world
  needs to know about it
- **Seasonal or conditional variations** — how it changes

## Status key

- **available** — ready for document creation
- **in-progress** — being written
- **done** — document complete

## Gaps

- No explicit faction or political structure in the game — social
  groupings are family/workplace-based and live on character cards.
- Cooking system has no dedicated reference document — recipe data
  is distributed across store inventories and item files.
- Woodcrafting and blacksmithing crafting systems not separately
  extracted (mentioned in store data but no dedicated source).
- Player skills/perks system extracted only as gate conditions on
  store items, not as a standalone concept document source.

## Cut from this index (character-level)

- Song crystals — collectible, not world-defining
- Relationships / marriage / children — inform individual character
  cards, not world documents
- Gossip and letters — character-level; may surface as event flavor
- Cameo visitors — will get their own character sections
