# Celine Spring — six-expression pilot

All expression candidates were generated independently from the approved neutral base, now located at `sprites/celine/spring/celine_spring_neutral.png`, using built-in ImageGen. None were generated from another expression image.

Every candidate uses Celine's fixed Spring background: soft aqua-teal → warm pale cream.

| Expression | File | Preliminary result |
|---|---|---|
| Neutral | `sprites/celine/spring/celine_spring_neutral.png` | Approved identity and outfit base. |
| Happy | `celine_spring_happy_candidate.png` | Clear quiet contentment; clean folded hands; distinct from Beaming. |
| Annoyed | `celine_spring_annoyed_candidate.png` | Clear restrained exasperation; temple gesture suits Celine; clean anatomy. |
| Angry | `celine_spring_angry_candidate.png` | Clear contained anger without aggression; forearm grip suits Celine. Lower ornament placement drifts slightly from the base. |
| Sad | `celine_spring_sad_candidate.png` | Clear withdrawal without tears; clean anatomy. Crop is wider than the rest because both hands are visible. |
| Surprised | `celine_spring_surprised_candidate.png` | Clear ordinary surprise; distinct from fear and Comedic Shock; crop remains close to the base. |

## Pilot questions

1. Is the face sufficiently consistent across all six images?
2. Is the wider Sad crop acceptable, or should sprite framing use a narrower fixed range even when gestures are requested?
3. Is the Angry ornament drift acceptable, or should that candidate be regenerated with stronger costume locking?
4. Are the five generated candidates ready to promote from diagnostic names to production filenames?

## Approval result

The user approved all six portraits. The candidates were promoted to `sprites/celine/spring/` and registered in its `manifest.json` using production filenames.
